How it works

From open data to a glowing route home

Ingest

Each month a Node job pulls street-level crimes from the police.uk API while the walkable street network comes from OpenStreetMap.

Score

Every street segment gets a risk_score from nearby incidents, weighted by category severity_weight.

Route

Fastest and safest options are compared. The chosen route glows across the dark map.

Learn

DBSCAN with a haversine metric finds hotspots without needing a cluster count and ignores noise.
